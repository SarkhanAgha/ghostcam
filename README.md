# GhostCam

Camera web app with a semi-transparent "ghost" of the previous shot for aligned / adjacent photos, plus feature-based panorama stitching.

Live: https://sarkhanagha.github.io/ghostcam/

- `index.html` - the app
- `opencv.js` - OpenCV.js 4.12 (Apache-2.0, via @techstark/opencv-js), loaded on demand for stitching
